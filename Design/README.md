# 🎨 DESIGN REFERENCES

Thư mục này chứa các tài liệu thiết kế UI/UX tham khảo từ dự án FlavorQuest.

## 📁 Cấu trúc

### Mockups/
Các mockup giao diện có thể tham khảo từ FlavorQuest:

1. **Welcome & Splash Screen**
   - Màn hình chào mừng
   - Hướng dẫn cấp quyền GPS
   - Onboarding flow

2. **Interactive Street Map**
   - Bản đồ tương tác với POI markers
   - Current location indicator
   - POI clusters
   - Distance indicators

3. **Browse Food POIs**
   - Danh sách POI gần đây
   - POI cards với distance
   - Filter và sort options

4. **Location Access Permission**
   - UI yêu cầu quyền GPS
   - Giải thích tại sao cần GPS
   - Fallback nếu bị từ chối

5. **Now Playing (Audio Player)**
   - Audio player với controls
   - Progress bar
   - Play/Pause/Stop
   - Volume control
   - TTS fallback toggle

6. **Active Audio Tour Dashboard**
   - Tour progress
   - Next POI preview
   - Auto/Manual mode toggle
   - Statistics (visited/total)

7. **App Settings**
   - Language selector
   - Audio settings
   - Map settings
   - Battery optimization
   - Offline mode

8. **Tour Summary & Completion**
   - Completed tour summary
   - Statistics
   - Share options
   - Restart tour

## 🎨 Design System

### Colors (tham khảo)
- Primary: #FF6B6B (Food theme - Red/Orange)
- Secondary: #4ECDC4 (Teal)
- Accent: #FFE66D (Yellow)
- Background: #F7F7F7
- Text: #2C3E50

### Typography
- Headings: Inter/SF Pro (Bold)
- Body: Inter/SF Pro (Regular)
- Vietnamese: Support for diacritics

### Icons
- Material Design Icons
- Food & Restaurant icons
- Map & Location icons
- Audio controls icons

## 📱 Platform Guidelines

### Android
- Material Design 3
- Bottom Navigation
- Floating Action Button

### iOS
- Human Interface Guidelines
- Tab Bar Navigation
- Native feel
