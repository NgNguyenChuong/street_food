# 📖 TÀI LIỆU DỰ ÁN

## Cấu trúc thư mục Documentation

### 1. ThuyetMinhDoAn.docx
Thuyết minh đồ án theo format:
- Chương 1: Giới thiệu
- Chương 2: Cơ sở lý thuyết  
- Chương 3: Phân tích thiết kế
- Chương 4: Cài đặt và kiểm thử
- Chương 5: Kết luận

### 2. Diagrams/
Các sơ đồ UML:
- **UseCaseDiagram.png** - Sơ đồ Use Case
- **ClassDiagram.png** - Sơ đồ lớp (quan trọng - thể hiện OOP)
- **SequenceDiagram.png** - Sơ đồ tuần tự
- **ERDiagram.png** - Sơ đồ Entity-Relationship (Database)

### 3. Screenshots/
Ảnh chụp màn hình demo các tính năng:
- Màn hình bản đồ
- Chi tiết POI
- QR Scanner
- Settings

### 4. Presentation/
Slide thuyết trình bảo vệ đồ án (15-20 slides)

## Lưu ý
- File Word nên dùng template chuẩn của trường
- Sơ đồ UML dùng tools như Draw.io, Visual Paradigm, StarUML
- Screenshots phải rõ nét, có caption giải thích
